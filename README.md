# nanrui_POC
本仓库用于收集和整理各类安全漏洞的POC及漏洞利用的EXP，服务于公司内部安全研究、渗透测试能力提升和漏洞应急响应等相关网安技术，不可随意外传！！！！！！！！！

# 维护流程
1、首先在网上找到相关的漏洞描述，了解该漏洞产生的原因，漏洞位置，漏洞危害，会造成什么样的影响；
2、其次根据漏洞的描述，可以在网上下载漏洞复现环境或者使用docker搭建漏洞复现环境，这样子可以在本地上搭建环境，方便用于后续的漏洞复现教学等；
3、利用网上公开的POC或者exp，在自己本地搭建的漏洞环境来进行复现，如果能rce的话就一定要rce，能提权就提权，这样子危害才明显；
4、使用公开的POC或者EXP进行复现成功之后，写一份漏洞复现报告，报告内容尽量包括漏洞如何搭建、POC或者EXP是如何使用的，最后的结果是什么样子的，尽量也把截图弄上去，不然其他人在复现的时候可能因为环境或者其他的原因，导致不能拿到相同的结果，这样子可以通过报告来判断哪个地方出现问题；
5、漏洞复现成功之后，可以根据POC写一个nuclei的模板，写完nuclei模板之后，也需要在本地环境或者真实环境进行验证，验证结果等相关内容也可以放到漏洞复现报告当中，在后续的渗透测试项目当中，如果遇到了这个环境，可以使用nuclei来进行验证，注意：nuclei模板里面的内容不能包含恶意脚本内容，只需要验证出漏洞即可，不可以加以利用，nuclei模板如果不知道怎么写的话可以借助ai来写，但是最后一定要进行验证，免得用不了或者产生危害。
